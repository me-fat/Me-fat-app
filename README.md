# ME fat v14

نسخة Flutter التجريبية لتطبيق **ME fat**.

## هذه النسخة
- التسجيل وتسجيل الدخول وحفظ الجلسة.
- بيانات المستخدم والهدف والمستوى.
- اختيار العضلة والتمارين.
- تسجيل الجولات والأوزان والتكرارات.
- سجل التمارين والتقدم.
- InBody ومقارنة القياسات.
- تعديل الحساب وتسجيل الخروج.
- تجهيز أسهل للتشغيل على iPhone.

## تشغيل iPhone
على جهاز Mac:

```bash
chmod +x ios_setup.sh
./ios_setup.sh
```

السكريبت ينشئ ملفات iOS، يضبط اسم **ME fat**، ثم يفتح Xcode. بعد ذلك اختر Apple Team واضغط Run على iPhone المتصل.

> بناء أو توقيع تطبيق iPhone لا يمكن تنفيذه من Windows/Linux؛ Apple تتطلب Xcode على macOS.
